# NMC2 – stavební výkresy

Veřejně dostupné PDF výkresy pro QR kódy použité na stavbě. Zdrojový
repozitář se skriptem pro generování přehledové stránky s QR kódy je
privátní; sem se nahrávají jen samotné výkresy, na které QR kódy odkazují.

Aktualizace výkresu: nahraďte soubor ve `vykresy/` souborem se stejným
názvem — URL i QR kód se nemění.
